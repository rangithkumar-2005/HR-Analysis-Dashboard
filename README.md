# 📊 HR Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **HR Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard provides a clear overview of employee data and helps analyze workforce trends based on gender, age, country, business unit, job title, and hiring and termination trends.

### 👥 Employee Headcount Analysis

The dashboard analyzes the total employee headcount and provides insights into the distribution of employees across different categories.

- Male Employees: 51

### 🎂 Employee Headcount by Age

Employee distribution is analyzed based on different age groups to understand workforce demographics.

### 🌍 Employee Headcount by Country

The dashboard provides country-wise employee distribution, including countries such as:

- United States
- China
- Brazil

### 🏢 Headcount Based on Business Unit

Employees are distributed across different business units, including:

- Sales
- Services
- HR
- IT

### 💼 Employee Headcount by Job Title

The dashboard provides insights into the number of employees working in different job roles, such as:

- IT
- Engineering
- Finance
- Sales
- HR
- Marketing
- Accounting

### 📈 Employee Headcount Volume Trend
